# 图书管理系统使用说明

## 系统简介
这是一个基于Python开发的轻量级图书管理系统，使用命令行交互方式，支持图书管理和借阅管理功能。

## 技术栈
- Python 3.8+
- 标准库：json, os, time, datetime
- 可选库：tabulate（用于美化表格输出）

## 功能特点
1. **图书管理**：
   - 新增图书（支持ISBN重复校验）
   - 查询图书（按书名/作者/ISBN）
   - 修改图书信息
   - 删除图书（检查未归还记录）

2. **借阅管理**：
   - 借阅图书（检查库存）
   - 归还图书
   - 查看借阅记录

3. **数据持久化**：
   - 自动保存到本地JSON文件
   - 启动时自动加载数据

4. **用户体验**：
   - 清晰的菜单系统
   - 友好的错误提示
   - 支持键盘中断操作

## 安装说明

### 1. 安装Python
确保你的系统已安装Python 3.8或更高版本。

### 2. 安装可选库（推荐）
为了获得更好的表格输出效果，建议安装tabulate库：

```bash
# Windows
python -m pip install tabulate

# macOS/Linux
pip3 install tabulate
```

## 运行说明

1. 下载 `library_system.py` 文件到本地目录
2. 打开命令行终端，进入文件所在目录
3. 运行以下命令：

```bash
# Windows
python library_system.py

# macOS/Linux
python3 library_system.py
```

## 操作流程

1. 启动程序后，会显示主菜单
2. 选择 "1. 图书管理" 进入图书管理子菜单
3. 选择 "2. 借阅管理" 进入借阅管理子菜单
4. 选择 "3. 退出系统" 保存数据并退出

## 数据文件
程序会在运行目录生成两个JSON文件：
- `books.json`：存储图书信息
- `borrows.json`：存储借阅记录

## 注意事项
1. 请确保程序有读写文件的权限
2. 输入ISBN时请确保唯一性
3. 借阅图书时请确保库存充足
4. 删除图书前请确保没有未归还的借阅记录

## 错误处理
程序已处理以下异常情况：
- 文件读写失败
- 输入格式错误
- 操作不存在的图书
- 库存不足
- 未归还的借阅记录
- 键盘中断操作

## 系统要求
- Python 3.8+
- 支持Windows、macOS、Linux操作系统
- 无需数据库或Web服务器
